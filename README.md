# Cogton AI

Marketing site for Cogton AI — AI-driven packaging optimization for 3PL and e-commerce operators.

Built with [Next.js](https://nextjs.org/), Tailwind CSS and [shadcn/ui](https://ui.shadcn.com/). Deployed on Netlify; no environment variables or database are required.

## Pages

- `/` — landing page
- `/features` — features
- `/productos/cartonizacion`, `/productos/catalogo` — product pages
- `/pricing` — savings calculator and quote form
- `/contact` — contact / demo request

## Running locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Building

```bash
pnpm build
```
